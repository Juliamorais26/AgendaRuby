# 📒 Agenda de Contatos em Ruby

Este é um projetinho simples que desenvolvi para treinar Ruby, foi a primeira vez que escrevi um sistema usando a linguagem.
Criei o sisteminha seguindo um vídeo do YouTube, aproveitando para entender melhor como Ruby funciona na prática.

## 📌 Sobre o sistema

O programa é um sistema de agenda de contatos que roda no terminal e permite:

- Listar todos os contatos
- Adicionar novos contatos
- Buscar um contato pelo nome
- Editar nome ou telefone
- Remover contatos

Tudo feito apenas com Ruby puro, usando arrays, hashes, métodos, condicionais e loops para praticar a base da linguagem.

## 🚀 Objetivo

O objetivo principal foi aprender Ruby do zero, colocando em prática o que vi no vídeo e entendendo melhor lógica, estrutura e sintaxe.
